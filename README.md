## Featured project

### [MovieLingo](https://movie-lingo.com) · 看电影之前，先学会里面的单词

[![MovieLingo](https://raw.githubusercontent.com/James18000/movielingo/main/screenshots/home.jpg)](https://movie-lingo.com)

Pick a movie and MovieLingo turns its English subtitles into a CEFR-graded (A1–C2) word list with the real film lines,
pronunciation and Chinese meanings, then teaches them with flashcards and spaced repetition.
Live with paying users in Malaysia.

**Built with:** JavaScript (PWA) · Python (NLTK, WordNet) · Cloudflare Workers · Supabase (Postgres, Google OAuth)
